# SoloWay test — тестовый канал

Здесь сборки **SoloWay test**: отдельное приложение (пакет `by.solovei.soloway.test`), которое ставится рядом с рабочим SoloWay и не мешает ему.
Новые версии сначала попадают сюда; на основной канал ([SoloWay-releases](https://github.com/soloveiby/SoloWay-releases)) — после проверки.

- Релизы — `SoloWay-NN.apk`, тестовое приложение обновляется отсюда само
- `institutions/` — каталог заведений тестового канала
